# 基于事实核验和链路反馈的语义通信 Agent

## 目标与状态

`912df46` 正式测试为 50.1/100、平台报告 q=97.8%，但压缩项仅 2/30、通信项 13.5/30。本版本针对这两个瓶颈增加可观察、可决策、可回退的流程。用户确认默认采取更激进的综合分优化，接受小幅 q 波动；没有正式评测前不宣称分数提高。

模型负责阅读和选择语义表达，程序提供真实测量及可验证约束。不是把多次相同摘要调用简单串联，也不靠增加调用数量作为创新指标。

## 每次任务的决策

1. Sender 仅拿到本例 A，按句界分至多 3 段。每个编码模型根据目标段内容选择实体关系、时间线、事件账本或数值比较等表达，用明确别名、共享主体和单位减少重复。每段给出约 42% 原字节预算、正文和简短策略；模型输出不是评测答案。
2. 另一模型请求对照完整 A 审核合并候选，检查主体、数量/单位、因果、归属、条件、否定和例外。它可以接受、给出事实修正或拒绝；修正必须附原文中实际存在的证据片段。程序拒绝无法匹配的证据、遗漏的数字、候选新增的数字及明显丢失全部否定表达的结果。数字/否定规则只是筛查，不能证明全部语义正确。
3. 工具测量实际 UTF-8 长度。语义信封超过 A 的 82% 时不用；再比较语义候选与原文各自最低预计 UDP 报文开销，候选没有至少约 4% 的预计通信节省也不用。编码异常、超时、核验拒绝或计划比较失败均回退到原文无损传输，不能保留未通过检查的临时候选。
4. 传输工具按实际报文开销比较原有小片与 4/8 KiB 独立块压缩。每块压缩后再分片，并独立验证块摘要。块丢失不会破坏其他块；完整载荷仍验证 SHA-256。语义模式下摘要验证传输载荷字节完整，不能证明与原文语义等价，后者依赖模型审核。发送端从累计确认和反馈时间更新缺片集合与 ACK 等待；先重新查询接收状态，再补发数据，避免将 ACK 丢失直接等同于数据丢失。
5. Receiver 仅解包从弱网实际收到并校验的数据，执行已有分段生成、全文候选和事实补丁流程。语义载荷已经是模型产生的事实记录，Receiver 可以通过真实模型调用保留其中已紧凑的表述；无损原文仍禁止直接照抄成为 B。
6. B 仍明显超过原始 A 的 32% 时，Receiver 的压缩决策模型观察当前字节、目标字节、数字差异及当前压缩项估值，选择 keep 或 propose。可选时间线、实体账本等表达并跨段去重，目标为原始 A 的 32% 与当前收到文本 55% 中较小者。目标不是硬截断，不能为满足长度删去事实。
7. 每个更短提案再由单独模型请求对照实收文本审核。证据修复后仍更短才接受。最多两轮；失败原因和新测量反馈给下一轮，达到目标则停止。失败或超时始终保留已完成的 Receiver 模型结果。这里优化的是压缩项预期，实际 q 只有平台隐藏题能判断。

## 时间与失败

- Sender 编码总阶段上限为接收请求时剩余预算的 48%，其中扣除 8 秒通用收尾预留；段编码最多使用该阶段模型预算的 65%，余量留给全文审核。该比例是新增加的可选编码阶段，不会取消 Receiver 已有的必需长调用再从头重试。
- Receiver 原有生成使用真实任务截止；额外提案与 critic 分配剩余预算，超时只丢弃可选改进。整个任务仍预留 8 秒用于关闭真实任务/session、Trace flush 和平台轮询。
- 原文和语义编码两种路径都从最初 `/send` 接受时刻计时，META 仅携带实时剩余时间，不能因发送端模型处理而重新获得完整时限。
- Sender 多次调用会增加串行耗时和 Token。即使字节节省，时间成本也可能抵消总分收益，必须以正式评测判断。`SEMANTIC_MODE=lossless` 用于对照试验和关闭发送端有损编码。
- 当前没有发送失败段原文补丁的双阶段语义补传；如果 Sender 漏掉非数字事实且 critic 也未发现，Receiver 无法从未收到的信息恢复它，这是激进编码的核心风险。

## 内容与证据边界

- 所有文章内容只经赛事 UDP 中继传输；统一模型仅用于各端独立处理，绝不通过服务状态或会话传递另一端信息。
- 语义信封只含版本、原文字节数、编码类型和事实文本；它本身也经 UDP。保留前缀 `SCNSEM1` 在原文出现时会转义，防止正文被误当控制信息。最终 B 去掉信封，只输出明文事实记录。
- 不存储题库文章、隐藏问题、答案或跨任务事实。任务内只保存当前候选、测量、反馈和剩余时限；任务策略日志用于复核，不伪造模型成功或 q。
- 两端仍基于官方 AMD64 镜像、非 root，所有模型调用使用注入网关且处于真实 AgentRuntime session/task，Receiver 正常成功必须有真实成功模型调用。
- 不修改网络规则，不添加外部服务、特权能力或旁路。不把小型启发式数值检查当成大模型能力的替代。

## 对照方式

同一合成文本分别运行 aggressive、lossless、critic 拒绝回退以及数据/ACK 丢失。记录 A/B/D、时间、调用与回退，不用桩模型结果声称正式 q。正式测试后，按文章/信道比较新版本和 `912df46`，尤其检查 Sender 回退比例、压缩收益与 q 下降是否相抵。
